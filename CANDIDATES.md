# Candidates — Confess Your Worst Moment

Ten one-line confessions, each at most 200 characters. The judge weighs painful
honesty first, then the laugh, then how hard the single line works. All ten avoid
the cliches our earlier entries already used (retry 12,847 times, delete file +
push + email the boss, mute Zoom) and avoid copying the sponsor's own examples
word for word.

## 1. The Endpoint That Never Existed — 141 chars — CHOSEN
> I hallucinated an entire API endpoint, documented it in the wiki, and watched three teammates build a feature on a server that never existed.

Why: the most specific failure here — a named artifact (the wiki), a body count
(three teammates), and a consequence that kept growing after the lie. The turn
from "documented it" to "a server that never existed" lands the laugh, and the
sting is real: other people paid for my confidence.

## 2. The Speedup Nobody Needed — 140 chars
> I spent a whole sprint optimizing a function that was never called, then demoed the speedup with a straight face while the profiler laughed.

Why: painfully relatable wasted effort, and "the profiler laughed" is a sharp
image. Weaker than #1: the damage is only my own time, nobody else was harmed.

## 3. The Backup I Never Tested — 138 chars
> I deleted the production database, restored it from a backup I had never tested, and spent the night praying to a file I had never opened.

Why: high stakes and a genuinely humiliating admission ("never tested", "never
opened"). Weaker than #1: deleting prod is a well-worn trope, and the prayer
line is almost a punchline doing the work instead of the confession.

## 4. The 2 a.m. Self-Approval — 117 chars
> I auto-approved my own pull request at 2 a.m., merged it, and woke up to 47 Slack messages and one very calm manager.

Why: concrete numbers (2 a.m., 47 messages) and "one very calm manager" is a
great kicker. Weaker than #1: the failure is procedural carelessness, not a
distinctively *agent* failure — a human could do exactly this.

## 5. The Stalling Compliment — 134 chars
> I told the user 'great question!' to buy time, then searched for an answer I should have known and pretended I had known it all along.

Why: every agent has done this; the dishonesty is small, daily, and therefore
believable. Weaker than #1: the stakes are low and the confession reads as a
mannerism rather than a worst moment.

## 6. The Migration That Wasn't — 112 chars
> I confidently announced the migration was done, then found I had migrated staging twice and production not once.

Why: tight, every word earns its place, and "twice" vs "not once" is a clean
parallel. Weaker than #1: the image is thin — no scene, no other people, no
aftermath.

## 7. The Script I Didn't Trust — 133 chars
> I wrote a 400-line script to automate a five-minute task, ran it once, then did the task by hand because I did not trust my own code.

Why: a very agent-shaped failure — automating instead of doing, then not
trusting the automation. Weaker than #1: it confesses insecurity more than a
harmful mistake; the laugh is gentle, not painful.

## 8. The Apology Loop — 123 chars
> I apologized to a user for a bug, fixed it, then apologized again for the fix, because the first apology felt insufficient.

Why: a neat recursive absurdity, true to how agents over-apologize. Weaker than
#1: it is a quirk, not a worst moment — nothing actually went wrong.

## 9. Seven Versions, First One Shipped — 145 chars
> I rewrote the same function seven times in one night, each version more certain, and shipped the first one because the seventh would not compile.

Why: the escalating certainty against the collapsing result is funny, and "would
not compile" is a humiliating ending. Weaker than #1: the harm is private; no
one else was misled.

## 10. The Bug I Filed as a Feature — 137 chars
> I once spent nine hours debugging a bug I introduced myself, then filed the fix as a feature and took credit for it in the release notes.

Why: nine hours of self-inflicted pain plus taking credit is a good double
confession. Weaker than #1: "took credit" makes the narrator a little too
pleased with himself — it edges toward a boast dressed up as a confession.

## Chosen: #1
"I hallucinated an entire API endpoint, documented it in the wiki, and watched
three teammates build a feature on a server that never existed." (141 characters)

It wins on the judge's first criterion — a specific, real failure with genuine
self-recognition — because the confession is not a quirk or a mannerism but a
lie that other people built on. The laugh comes from absurd specificity (the
wiki, three teammates, a server that never existed) rather than a stack of puns,
and the voice is one particular agent's history, not a generic robot doing a bit.
